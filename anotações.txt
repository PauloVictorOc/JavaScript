Entendendo Operadores:
-> Os operadores Js são usados para atribuir valores, comparar valores, executar aritiméticas e muito mais.

São eles: + - * / = ++ -- += -= /= && || etc...

Separados em 6 "categorias":
    1 - Operadores Aritiméticos(matematicos)
    2 - Operadores de Atribuição
    3 - Operadores de Sequência - juntar duas strings
    4 - Operadores de Comparação - Verdadeiro ou Falso(True or False)
    5 - Operadores Condicional (Ternário) - condicional, caso algo seja uma coisa e não outra(if and else)
    6 - Operadores Lógicos


Funções:
    Uma função em Js é um bloco de código projetado para executar uma tarefa específica.
    É como uma pequena "fábrica" onde você faz uma entrada e ele te dá uma saída.

    Pode ser encarado como "mini-programas" projetados para fazer uma tarefa que vai contribuir para todo código.
    Uma função em Js é executada quando "algo" a invoca.

Objetos:
    Objetos são basicamente variáveis com muitos valores dentro
    Ex: const carro = {marca:"Chev", modelo:"palio", ano:"2016"}

    Os valores dentro de um carro são chamados de prorpiedades

    Objetos também podem ter métodos. Um métodos é uma função colocadas dentro de uma prorpiedade.

Eventos:
Eventos são ações disparadas pela interação dos usuarios na página.
É o correto manejo desses eventos que tornam as páginas interatibas e dinamicas

Existem muitos eventos. Esses são os mais utilizados.

onclick -> Disparando uma função quando o usuário clicar no elemento
ondblclick -> Disparando uma função quando o usuário clicar duas vezes no elemento
onmouseover -> Disparando uma função quando o usuário passar o mouse sobre o elemento
onmouseout -> Disparando uma função quando o usuário tirar o mouse do elemento
onmousemove -> Disparando uma função quando o usuário mover o mouse sobre o elemento
onmousedown -> Disparando uma função quando o usuário pressionar o botão do mouse sobre o elemento
onmouseup -> Disparando uma função quando o usuário soltar o botão do mouse sobre o elemento
onfocus -> Disparando uma função quando o usuário focar no elemento
onchange -> Disparando uma função quando o usuário alterar o valor do elemento
onblur -> Disparando uma função quando o usuário tirar o foco do elemento
onkeydown -> Disparando uma função quando o usuário pressionar uma tecla do teclado
onekeyup -> Disparando uma função quando o usuário soltar uma tecla do teclado
onekeypress -> Disparando uma função quando o usuário pressionar e soltar uma tecla do teclado
onload -> Disparando uma função quando a página for carregada
onresize -> Disparando uma função quando a página for redimensionada

ARRAYS:
    Os arrays JS são usados para armazenar vários valores em uma única variavel. Diferente dos objetos, qye funcionam com propriedades ou "nomes" que você dá para os intens dentro dele, os arrays não possuem propriedades. O item dentro dele é encontrado pela posição.

    Imagine um array como uma lista de iten, com controle, por ordem de posição dentro dele.

    Ex: const lista = ["arroz", "feilão", "macarrão", "leite"];

    A lista[0] (lista na posição 0) vai conter o valor "arroz".
    A lista[1] (lista na posição 1) vai conter o valor "feijão".
    e assim continua...
